# Order AI

Order AI to rozszerzenie Microsoft Edge i Google Chrome oraz lokalny panel pomagający przygotowywać oferty Allegro na podstawie danych produktów z Amazon.

## Funkcje

- Import tytułu, opisu, zdjęć i podstawowej specyfikacji produktu.
- Obsługa wielu regionalnych stron Amazon.
- Edycja treści, wybór zdjęć i podgląd oferty.
- Opcjonalne tłumaczenie i poprawa tekstu przez OpenAI API, zatwierdzane przez użytkownika.
- Zapisywanie szkiców na komputerze użytkownika.
- Połączenie konta Allegro przez OAuth i odczyt loginu.

## Integracja Allegro

Aplikacja korzysta z uprawnień odczytu danych konta, odczytu i zarządzania ofertami oraz odczytu ustawień sprzedaży.

Tworzenie nieaktywnych ofert jest w przygotowaniu. Obecna wersja nie wysyła ani nie publikuje ofert.

## Dane

Klucze API i tokeny przechowywane są lokalnie na komputerze użytkownika. Do poprawy przez AI przesyłana jest treść produktu. Aplikacja nie odczytuje zamówień ani danych płatności.
